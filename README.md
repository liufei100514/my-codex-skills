# my-codex-skills

个人 Codex Skills 仓库，用于沉淀、管理和复用经过验证的工作流与技能。

## 目录

- `skills/`：正式使用的个人 Skills
- `templates/basic-skill/`：新 Skill 模板

## 使用原则

1. 一个 Skill 一个目录，并包含 `SKILL.md`。
2. 只沉淀稳定偏好、验证过的流程和可复用经验。
3. 区分原文事实、已验证结论与推断。
4. 涉及时效信息时重新验证。
5. 安装、升级或删除 Skill 前先人工确认。

## 推荐结构

```text
skills/
  example-skill/
    SKILL.md
    scripts/
    references/
```
