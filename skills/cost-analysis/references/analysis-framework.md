# 分析框架细目与表格模板

## 第 1 层：总量与趋势

**产出表**：月份 | 营业收入 | 营业成本 | 毛利率 | 期间费用 | 营业利润 | 净利润

**要点**
- 用「本期金额」做趋势，用「本年累计」做总额
- 标出亏损月、毛利率最高/最低月，并解释拐点（不要只说「波动」）
- 季度聚合：Q1/Q2/Q3 的毛利率、费用率、营业利润率变化，判断改善来自「毛利率」还是「摊薄」

**常见误读**：2 月毛利率高 ≠ 经营改善，往往是低基数 + 高毛利品类占比被动上升。

## 第 2 层：利润瀑布（每 100 元收入去哪了）

**模板**

**要点**：一眼看出「钱被谁吃掉」。制造业通常是材料一项决定生死。

## 第 3 层：成本结构

**产出表**：类别 | 材料 | 材料占比 | 人工 | 人工占比 | 制造 | 制造占比 | 成本/收入

**判断句**
- 材料占比 > 80%：成本由「进价 vs 售价」决定，内部降本空间极小
- 材料占比 50%—80%：采购与工艺并重
- 材料占比 < 50%：人工/效率是主战场

**单位成本矩阵**：类别 | 单位售价（元/kg）| 单位成本 | 单位毛利 | 1 月 vs 10 月变化
→ 用来判断「是涨价还是降本带来的改善」，两者可持续性完全不同。

## 第 4 层：毛利结构（三维）

### 4.1 品类
类别 | 收入 | 收入占比 | 毛利 | 毛利率 | 毛利占比 | 边际毛利率 | 单吨毛利

**找错配**：收入占比高但毛利占比低的品类，是「体量大、赚钱少」，必须单独定价策略。

### 4.2 客户
客户 | 收入 | 毛利 | 毛利率 | 边际毛利率；再算 CR5/CR10/CR20

**三张风险清单**
1. 全期毛利为负的客户（停做或提价）
2. 毛利率 <3% 的客户（按边际毛利率分档：≥15% 保量 / 8%—15% 限期提价 / <8% 退出）
3. 收入>50 万且毛利率<3% 的「大而薄」客户（逐户过会）

### 4.3 型号
物料名称+规格 | 收入 | 毛利 | 毛利率 | 涉及客户数

**找产品线级亏损**：同一系列多个型号集体为负 = 定价策略问题，不是个别订单问题。

## 第 5 层：费用结构

### 5.1 三分
固定 / 半固定 / 变动 的合计、占比、月均；刚性费用 = 固定 + 半固定

**关键指标**：变动费用月均 ÷ 收入 = 收入下行时的缓冲垫厚度。

### 5.2 科目 TOP15
科目 | 合计 | 占费用比 | 月均 | 最大月 | 最小月 | 波动率

**盯三样**：增长最快的科目、出现负数的科目、一次性科目。

### 5.3 部门
部门/车间 | 合计 | 占比 | 月均 | 占收入

**要点**：车间是成本中心，要按「单位电耗/水耗/工时」设标准，而不是只看总额。

### 5.4 人力
- 编制（人）× 人均月薪 = 工资总额；拆「人数效应」与「薪酬效应」
- 社保/工资比率：突然上升要查基数或参保口径
- 人力总成本（工资+社保+公积金）占收入比，是唯一可管理的刚性块

## 第 6 层：边际贡献与盈亏平衡

```
边际毛利 = 收入 − 材料成本          （只扣材料，其余都算固定）
边际毛利率 = 边际毛利 ÷ 收入        ← 报价底线
刚性支出 = 人工 + 制造费用 + 期间费用 + 税金
盈亏平衡收入 = 刚性支出 ÷ 边际毛利率
安全边际 = (实际收入 − 盈亏平衡收入) ÷ 实际收入
```

**情景表**：月收入 1,000/1,200/1,500/1,800/2,100 万 → 对应的刚性费用率、总费用率

## 第 7 层：量价拆分

```
Δ收入 = (Q1−Q0)·P0 + Q0·(P1−P0) + (Q1−Q0)·(P1−P0)
        销量效应      单价效应        交叉项
```

**判断句**
- 销量效应为正且占主导 → 放量驱动，要看产能与费用摊薄
- 单价效应为负 → 以价换量，必须查返利与低毛利订单
- 交叉项大 → 结构变化剧烈（品类/客户结构切换）

## 输出：利润改善桥

举措 | 年化影响 | 相当于营业利润 | 实现难度 | 责任部门 | 验收指标

最后给三档情景（保守 40% / 中性 60% / 进取 100% 实现率），不要给单点预测。

## 附：脚本骨架（pandas / openpyxl）

```python
import openpyxl
from collections import defaultdict

wb = openpyxl.load_workbook(path, data_only=True)
ws = wb["明细"]
hdr = [ws.cell(row=1, column=c).value for c in range(1, ws.max_column + 1)]
I = {h: i for i, h in enumerate(hdr)}

def num(r, k):
    v = ws.cell(row=r, column=I[k] + 1).value
    return float(v) if isinstance(v, (int, float)) else 0.0

agg = defaultdict(lambda: defaultdict(float))
for r in range(2, ws.max_row + 1):
    if ws.cell(row=r, column=1).value is None:
        continue
    key = ws.cell(row=r, column=I["类别"] + 1).value
    for f in ("出库数量", "出库金额2", "出库总成本2", "毛利", "边际毛利"):
        agg[key][f] += num(r, f)

# 边际毛利率、单位成本、瀑布、量价拆分 均从 agg 继续
```

**读表三原则**
1. 先打印 `max_row / max_column` 与表头，再动数据
2. 用 `data_only=True` 读值；要保留公式就 `data_only=False` 另存
3. 源文件只读，产出另存新文件，绝不在原始表上改
